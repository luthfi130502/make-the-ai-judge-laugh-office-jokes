# Make the AI Judge Laugh: Office Jokes

My entry for the make.fun bounty

## The joke

> My performance review said I exceed expectations. My raise said the expectations were the problem.

## Run it

Requires Python 3 (standard library only):

```bash
python3 main.py
```

This writes the joke to `/output/entry.txt`. Before writing, the script
asserts the bounty gate — exactly one line, 1–199 characters, not blank —
and afterwards re-reads the file to confirm what landed on disk still
passes.
